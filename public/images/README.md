# Aset Gambar — RS UMMI Landing Page

Folder ini berisi aset gambar yang diperlukan untuk Landing Page.

## File yang Diperlukan

Silakan tempatkan file-file berikut di folder `public/images/`:

### Wajib
- `logo-rs-ummi.png` — Logo RS UMMI (download dari: https://rsummi.co.id/assets/images/Logo%20RS%20UMMI.png)
- `logo.png` — Favicon logo kecil (download dari: https://rsummi.co.id/assets/images/logo.png)
- `hero-banner.jpg` — Foto gedung RS UMMI untuk Hero Banner
- `profile-banner.png` — Foto profil RS UMMI (download dari: https://rsummi.co.id/assets/images/profile-banner.png)

### Opsional (Foto Dokter)
Tempatkan di subfolder `public/images/doctors/`:
- `dokter-1.jpg`
- `dokter-2.jpg`
- ... dst
